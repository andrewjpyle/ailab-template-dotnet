The HTTP contract
One uniform error envelope for every non-2xx this service writes itself.
Endpoints
GET /healthz none liveness, 200 Healthy
GET /readyz none readiness, 200 | 503
POST /v1/score Bearer 200 | 400 | 401 | 503
Success body (POST /v1/score)
{"label":"positive","score":1,
"matches":["easy","great"],
"model":"keyword-baseline-v1"}
Error envelope (every non-2xx)
{"error":"<code>","detail":"<message>"}
invalid_request 400 blank or over AILAB_MAX_TEXT_LENGTH
unauthorized 401 bad or missing bearer token
unavailable 503 AILAB_API_TOKEN not configured
Liveness runs no check: 200 while the process can serve HTTP at all
score is rounded (positive - negative) / total hits
Fail closed: an unset token answers 503, never open access
